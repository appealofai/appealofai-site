# Article images

Drop article-specific image exports here.

Expected filenames:

- `wide.webp` and/or `wide.jpg` for hero, cards, and wide previews.
- `square.webp` and/or `square.jpg` for square crops if needed later.
- `portrait.webp` and/or `portrait.jpg` for tall crops if needed later.

The current CSS/JS will automatically prefer `wide.webp`, then `wide.jpg`.
